相机：
xdg-open 'http://127.0.0.1:8767/'
如果页面提示无法连接，先启动相机服务：
bash /home/yc/UR3/camera/start_h_tracking.sh
保持该终端运行，再执行打开网页的命令。

机械臂：
指定磁铁中心目标点（table_world 桌面世界坐标，单位 mm）
首次命令先去掉 --execute 检查规划，通过后再执行：

source /home/yc/UR3/ros2_env.sh && ros2 run ur3_magnetic_control magnet_trajectory point --target-mm 320 160 400 --motor-rpm 10 --no --execute

--no：不保存本条命令的任何数据文件，包括临时记录和 ROS 文件日志。
--no camera：不启动相机、不保存相机数据；其他数据正常记录，独立相机服务不受影响。
--motor-rpm -10：电机以 10 rpm 反转。
只改 XY、保持当前磁铁高度：把 --target-mm 146 146 400 换成 --target-xy-mm 146 146。


桌面程序：
bash /home/yc/UR3/robot/start_ze300_gui.sh
bash /home/yc/UR3/camera/start_flir_camera.sh
FLIR 跟踪已运行时会打开现有跟踪页面；未运行时打开全分辨率查看器。


电机停止转动：
source /home/yc/UR3/ros2_env.sh && ros2 run ur3_magnetic_control ze300_motor speed 0
电机以最小距离回归原点
source /home/yc/UR3/ros2_env.sh && ros2 run ur3_magnetic_control ze300_motor home

断电重连自动恢复磁铁原点（服务状态）：
systemctl --user status ur3-motor-origin.service
手动恢复已保存的磁铁水平原点：
source /home/yc/UR3/ros2_env.sh && ros2 run ur3_magnetic_control ze300_motor restore-origin
