# 机械臂规划与执行记录

这里是 2026-09-19 实验生成的审核材料，包括只读基线、规划草案、碰撞检查、RTDE
采样和执行结果。它们不是源代码，也不是可以直接发送给机械臂的轨迹库。

- `*_baseline`、`*_read_only*`、`*_audit*`：基线或离线审核，通常没有发送运动。
- `*_execution_*`：可能包含实机执行记录；是否实际发送必须查看目录内
  `report.json`/`summary.json` 的 `motion_sent` 和完成状态。
- 名称中的旧净空数值只描述生成当时的策略。当前策略发生变化后，旧哈希和旧审核
  全部失效，必须从当前状态重新规划。
- 不要为“整理目录”而删除失败记录；失败原因和停车数据同样属于安全审计证据。

`docs/history/`。
