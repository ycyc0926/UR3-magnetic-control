# 相机跟踪实验记录

每个时间戳目录是一场相机/H 跟踪会话，内部可能含 `positions.csv`、逐帧诊断、事件
日志和若干 `clip_*` 录像。它们是原始实验数据，不属于程序源码，也不会自动清理。

已确认 H 在画面中明显移动的连续录像共有四段，快捷链接见相邻的
[`camera/motion_examples/`](../motion_examples/README.md)：

| 录像时间 | 净位移 | 主要运动区间 |
|---|---:|---:|
| 14:36:20 | 77.4 mm | 约第 8–22 秒 |
| 15:03:56 | 23.6 mm | 约第 15–18 秒 |
| 15:14:13 | 23.5 mm | 约第 12–15 秒 |
| 17:09:31 | 14.0 mm | 约第 14–16 秒 |

17:15 之后现存录像的净变化均不超过约 0.22 mm，属于静止/视觉波动量级，不应标成
H 运动录像。12:31 左右的一次磁驱动记录显示前后位移约 57.8 mm，但当时没有保存
连续原始视频，只有 CSV 和观察报告。
