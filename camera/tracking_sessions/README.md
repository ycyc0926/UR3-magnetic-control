# 相机跟踪实验记录

每个时间戳目录是一场相机/H 跟踪会话，内部可能含 `positions.csv`、逐帧诊断、事件
日志和若干 `clip_*` 录像。它们是原始实验数据，不属于程序源码。

2026-09-22 之后新录制的每段视频会在结束时自动筛选：中心活动范围达到
0.5 mm 的录像保留，并在同一 `clip_*` 目录生成 `trajectory.png`；可靠跟踪下未达
阈值的静止录像会连同该段目录删除。跟踪数据不足的录像会保留，避免误删。
